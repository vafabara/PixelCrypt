# PixelCrypt

PixelCrypt is a simple Python project that encodes text into an RGB image and decodes the image back into the original text.

## Features

- Encode text into an RGB image
- Decode text from an encoded image
- Save images as PNG
- Custom save location
- Custom file name
- Automatic PNG extension
- Image preview after encoding
- Simple terminal interface
